# RISC-V Instruction Set Simulator

## Overview

This project is a basic RISC-V Instruction Set Simulator developed as part of the Valen Labs Embedded Systems & Edge AI Research Internship.

## Features

- CPU Module
- Program Counter
- Register File (32 Registers)
- Instruction Memory
- Instruction Decoder
- Execution Unit (ALU)
- Memory Unit
- Branch Support

## Technologies

- C++
- CMake
- Git
- VS Code
- RARS
- QEMU
